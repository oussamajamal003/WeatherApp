# Review Checklist

## Architecture

- Correct folder structure
- Reusable components
- No duplicated logic
- Clean separation of concerns

---

## Code Quality

- Readable code
- TypeScript strict
- No `any`
- No dead code
- No unnecessary complexity

---

## UI

- Responsive
- Accessible
- Consistent design
- Loading state
- Error state
- Empty state

---

## API

- Uses service layer
- Handles errors
- No direct API calls in components

---

## Performance

- No unnecessary renders
- Optimized queries
- Lazy loading where appropriate

---

## Testing

- Tests added
- Existing tests pass

---

## Documentation

- Documentation updated if needed

---

## CI

- ESLint passes
- TypeScript passes
- Tests pass
- Build succeeds

---

## Decision

- ✅ Approve
- ⚠ Request Changes
- ❌ Reject
