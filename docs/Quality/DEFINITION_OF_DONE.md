# Definition of Done

A task is complete only when all requirements below are satisfied.

---

## Functionality

- Feature works as expected.
- Edge cases handled.
- No known critical bugs.

---

## Code Quality

- Clean and readable.
- TypeScript strict.
- No unused code.
- No duplicated logic.

---

## UI

- Responsive
- Accessible
- Consistent with design
- Loading, error, and empty states implemented

---

## Testing

- Tests added or updated.
- All tests pass.

---

## Documentation

- Relevant documentation updated.

---

## Quality

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

All commands pass successfully.

---

## Git

- Feature branch used.
- Conventional Commit created.
- Pull Request opened.

---

## CI

- All GitHub Actions succeed.

---

## Ready for Merge

The task is ready only if:

- ✅ Code Review Approved
- ✅ CI Passing
- ✅ Documentation Updated
- ✅ Definition of Done Satisfied
