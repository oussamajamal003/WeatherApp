# WeatherApp Design Specification

## Purpose

This directory contains the approved WeatherApp design specification.

Every screenshot in this directory is part of the approved UI.

Developers must implement the application using these screenshots as the primary visual reference.

## Reading Order

1. Cover
2. Tokens
3. Variables
4. Components
5. Specs
6. Layouts
7. Playground
8. Weather UI

## Rules

- Read `FIGMA_IMPLEMENTATION_RULES.md` before writing code.
- Review the relevant screenshots before implementing a feature.
- Do not invent UI.
- If a design is ambiguous, stop and request clarification.
- Treat the screenshots as the visual source of truth and the engineering documentation as the implementation source of truth.
