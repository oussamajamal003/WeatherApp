# Weather UI

## Purpose

Contains reusable weather-specific components.

## Includes

- Weather Card
- Forecast Card
- Hourly Forecast
- Temperature
- Wind
- Humidity
- Air Quality
- UV Index
- Sunrise
- Sunset
- Search Bar

## Implementation Rules

Build these components only after the Design Tokens, Theme, Layouts and Foundation Components have been implemented.

Implement using reusable foundation components.

Do not include business logic.

Use mock props until API integration is introduced.
