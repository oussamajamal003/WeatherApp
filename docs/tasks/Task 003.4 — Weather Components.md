# Component Architecture

Every Weather component must:

- Be reusable.
- Be composable.
- Be fully typed.
- Receive data through props only.
- Be independent from API calls.
- Be independent from React Query.
- Be independent from application state.
- Be independent from routing.

Components must not fetch data.

Components must not contain business logic.

Components must not perform formatting that belongs in utilities.

---
