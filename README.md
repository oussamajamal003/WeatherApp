# WeatherApp

A professional, modern, production-quality weather application built using React 19, TypeScript, and Vite.
This project is architected with clean design patterns and standard enterprise conventions.

## Features
- **Modern Stack:** React 19, Vite, TypeScript, Tailwind CSS
- **Code Quality:** ESLint (flat config), Prettier, Husky, lint-staged
- **Testing:** Vitest, React Testing Library
- **State & Data:** TanStack Query, Axios
- **Architecture:** Feature-based modular structure

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Copy `.env.example` to `.env` and provide your API keys
4. Run `npm run dev` to start the development server
